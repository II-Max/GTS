## 2024-05-24 - Firebase Realtime Database Shallow Queries for Counting
**Learning:** In Firebase Realtime Database, querying a node with `.get()` downloads the entire object tree underneath it. If the application only needs to count the number of top-level children (e.g., total users, total problems), this is a significant memory and bandwidth bottleneck. The `shallow=True` parameter natively supported by the Firebase Admin SDK (`firebase_admin.db.Reference.get(shallow=True)`) forces the database to return only the top-level keys mapped to `True` (e.g., `{"key1": True, "key2": True}`), allowing efficient counting without retrieving heavy nested data.
**Action:** When counting records in Firebase Realtime Database, always use `shallow=True` to avoid downloading full objects. This is a critical pattern for scaling dashboards or stats endpoints.
