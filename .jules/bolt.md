## 2025-02-27 - Server-side Filtering for Firebase Queries
**Learning:** When retrieving ranked lists from Firebase RTDB (like leaderboards), downloading the entire node just to sort and slice the top N items client-side creates a significant O(N) bandwidth and memory bottleneck as the database grows.
**Action:** Always utilize server-side query limitations by adding `.indexOn` to `database.rules.json` and fetching with `.orderByChild().limitToLast(N)`. When combining this with secondary sorting logic, handle the tie-breaker logic locally for the N items returned since Firebase RTDB does not natively support sorting by multiple keys simultaneously. Additionally, remember to extract data via `snap.forEach()` instead of `Object.entries(snap.val())` to safely preserve query ordering before performing additional client-side logic.
